# 스킬 카테고리

## Category 1: 문서·자산 생성

코드, 문서, 설정 파일 등을 생성하는 스킬

**예시:**
- 코드 생성기
- 문서 작성기
- 설정 파일 템플릿

**특징:**
- 출력물이 명확함
- assets/ 폴더에 템플릿 저장

## Category 2: 워크플로 자동화

빌드, 배포, 테스트 등 반복 작업을 자동화하는 스킬

**예시:**
- 빌드 스크립트
- 배포 자동화
- 테스트 실행기

**특징:**
- scripts/ 폴더에 실행 스크립트 저장
- 명령어 실행 단계가 명확함

## Category 3: MCP 도구 강화

외부 API, 서비스와 연동하는 스킬

**예시:**
- API 클라이언트
- 외부 서비스 연동
- 데이터 변환기

**특징:**
- 외부 의존성 있음
- 인증/설정 필요할 수 있음
