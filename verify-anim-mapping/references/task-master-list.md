## 에이전트 검증 가이드

### ID 변환 규칙

```
task_tm_no → task_num: 하이픈 제거 (21-00-07 → 210007)
animation → AnimId: animation // 10
animation → IsCockpit: animation % 10 (0=외부, 1=조종석내부)
```

### 엑셀 컬럼 (인덱스)

| 열 | 인덱스 | 이름 | 용도 |
|----|--------|------|------|
| B | 1 | sequence | VCBT 여부 |
| D | 3 | FA50M_system | 계통 (영문) |
| F | 5 | Job guide | 훈련절차명 (영문) |
| G | 6 | shot code | `XXXXXX_NNN_NN` (task_step_sub) |
| H | 7 | TO_num | 절차번호 |
| I | 8 | Story | 절차내용 (한글) |

### shot code 파싱

```
shot code: XXXXXX_NNN_NN
  XXXXXX = task_num (6자리)
  NNN    = step_no
  NN     = sub_no
```

### DB 쿼리 (검증용)

```sql
-- 1. task의 animation 목록
SELECT DISTINCT step_no, animation
FROM tbl_step
WHERE step_task_id = {TASK_ID} AND animation IS NOT NULL AND animation > 0
ORDER BY animation;

-- 2. task의 절차 내용 (영문)
SELECT ms_step_no, ms_step_sub_no, ms_step_description
FROM tbl_main_step
WHERE ms_task_id = {TASK_ID}
ORDER BY ms_step_no, ms_step_sub_no;
```
