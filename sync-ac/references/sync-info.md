# 동기화 정보

## 동기화 대상 폴더

| 폴더 | 설명 |
|------|------|
| Binaries | 빌드된 바이너리 |
| Source | 소스 코드 |
| Plugins | 플러그인 |
| Content | 콘텐츠 에셋 |
| Intermediate | 빌드 중간 파일 (리빌드 방지) |

## 제외 항목

**Config 폴더는 동기화 제외**

각 프로젝트별 설정을 유지하기 위해 Config 폴더는 동기화하지 않습니다.

## robocopy 옵션

| 옵션 | 설명 |
|------|------|
| `/MIR` | 미러링 (대상을 소스와 동일하게) |
| `/NJH` | 작업 헤더 없음 |
| `/NJS` | 작업 요약 없음 |
| `/NDL` | 디렉토리 목록 없음 |
| `/NFL` | 파일 목록 없음 |
| `/NC` | 클래스 없음 |
| `/NS` | 크기 없음 |

## 종료 코드

| 코드 | 의미 |
|------|------|
| 0 | 변경 없음 |
| 1 | 파일 복사됨 |
| 2+ | 경고 또는 오류 |
